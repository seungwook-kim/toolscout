# routes/

웹앱 화면과 기능 API 라우터. 상태: 예정 (계획안 9.3).

## 파일
- 웹앱 화면(`/`), 브리핑·피드백·질문 API(`/api/`), 관리자 트레이스 링크 (예정)

## 들어오고 나가는 데이터
- 들어옴: 브라우저 요청, 이메일 링크 버튼(서명 토큰)
- 나감: 카드 화면, 피드백 기록, 질문 답변

## 관련
- 루트 `main.py`: 이 라우터를 FastAPI 앱에 붙인다
- `web/`: 정적 파일
