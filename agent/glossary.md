# 해설가 용어집 (초안 30개)

해설가 시스템 프롬프트에 그대로 붙는다. 표기와 뜻을 여기 한 곳에서만 고친다.

## 표기 원칙
- 회사·제품·저장소 이름은 원문 그대로 쓴다 (OpenAI, Anthropic, Claude, Gemini, GitHub, n8n, Notion)
- 과장하지 않는다. "혁신적", "게임 체인저" 같은 말을 쓰지 않는다
- 원문에 없는 수치·기능을 만들지 않는다

## 용어
1. LLM: 거대 언어 모델. "LLM"으로 쓴다
2. 에이전트: 도구를 골라 쓰며 여러 단계를 스스로 진행하는 LLM 프로그램
3. 에이전트 프레임워크: 에이전트를 만드는 라이브러리 (예: LangGraph, CrewAI)
4. MCP: Model Context Protocol. LLM 앱과 도구를 잇는 표준 규약. "MCP"로 쓴다
5. MCP 서버: 도구·리소스를 MCP로 제공하는 프로그램
6. 원격 MCP: 설치 없이 주소로 붙는 MCP 서버
7. 도구 호출: 모델이 정해진 함수를 부르도록 요청하는 기능. "function calling"도 도구 호출로 쓴다
8. 스킬: 에이전트가 불러 쓰는 작업 설명서 묶음 (SKILL.md)
9. 프롬프트: 모델에 주는 지시문
10. 시스템 프롬프트: 대화 전체에 적용되는 기본 지시문
11. 컨텍스트 윈도: 모델이 한 번에 받을 수 있는 입력 길이
12. 토큰: 모델이 글을 나눠 세는 단위. 요금과 한도의 기준
13. 추론 모델: 답하기 전에 생각 과정을 거치는 모델
14. 멀티모달: 글 외에 이미지·음성 등을 함께 다루는 것
15. 오픈 웨이트 모델: 가중치를 공개한 모델. 코드까지 공개된 오픈소스와 구분한다
16. 로컬 모델: 내 컴퓨터나 사내 서버에서 돌리는 모델
17. 양자화: 모델을 가볍게 만들려고 숫자 정밀도를 낮추는 것
18. 파인튜닝: 기존 모델을 내 데이터로 추가 학습시키는 것
19. RAG: 검색 증강 생성. 필요한 문서를 찾아 붙여 답하게 하는 방식
20. 임베딩: 글의 의미를 숫자 벡터로 바꾼 것
21. 벤치마크: 모델 성능을 비교하는 표준 시험
22. 레이트 리밋: 정해진 시간당 호출 횟수 제한
23. API 키: 서비스 호출 권한을 증명하는 비밀 문자열. 값은 절대 적지 않는다
24. SDK: 서비스를 코드에서 쓰기 쉽게 만든 라이브러리
25. 워크플로 자동화: 작업을 정해진 순서로 자동 실행하는 것 (예: n8n)
26. 노코드·로우코드: 코드를 거의 쓰지 않고 화면에서 조립하는 개발 방식
27. 샌드박스: 바깥과 격리된 실행 환경
28. 프롬프트 인젝션: 외부 텍스트에 숨긴 지시로 모델을 조종하려는 공격
29. 가드레일: 모델 입출력을 검사해 위험한 동작을 막는 장치
30. 할루시네이션: 근거 없는 내용을 사실처럼 만들어 내는 현상
