toolscout 디자인 기준

리디자인 1·2차 회의 합의안(2026-10-08)을 코드로 옮긴 공통 체계예요. 이 문서는 web/app.css·app.js·cards.js·ask.js를 그대로 불러와 견본을 그려요. 맨 위 상단바도 실제 TS.shell 결과예요(API 응답만 가짜).

계정테마

원칙

  • 메일처럼 읽던 화면을 매일 처리하는 보드로. 검정 마스트헤드·760px 한 줄 기둥을 걷고 56px 상단바(모바일 52px + 하단 탭), 최대 1160px 보드, 뉴스 7 / 도구 5 두 레인
  • 탐색 자리는 어디서나 같게. 768px 이상은 상단바 탭, 미만은 하단 탭. 질문은 페이지가 아니라 시트. 갈 수 없는 탭은 그리지 않는다
  • 색은 세 가지 용도로만. 블레이즈 파랑은 '나 기준'(로고·현재 탭·포커스·나에게·나와 관련 눈금·선택 워시), 상태색은 검증·위험 신호·원문 확인·폼 오류, 나머지는 푸른 회색 단계
  • 채움은 행동, 워시는 상태. 잉크 채움 주 버튼은 화면당 하나. 선택·눌림은 블레이즈 워시 + 테두리 + 글자 변화
  • 색만으로 뜻을 전하지 않기. 상태는 인라인 SVG 아이콘 + 글자. 이모지·유니코드 기호는 아이콘으로 쓰지 않는다. 키 필요는 결함이 아니라 중립 열쇠
  • 숫자는 근거로만. 파이프라인은 mono 13px 한 줄. 큰 숫자 타일·비율 막대 없음. 미터는 분모가 작은 '검증 N/M'에만
  • 없는 데이터는 그리지 않기. 업계 중요도·N곳 보도·새 버전 a → b는 카드 데이터에 칸이 생긴 뒤에 그린다
  • 몸에 맞는 크기. 터치 44px, 입력 글자 16px, 주요 버튼·입력 48px, 한글 최소 13px(12px는 mono 숫자·라틴만), 390px에서 가로 스크롤 없음
  • 모달·confirm() 없음. 되돌릴 수 있으면 바로 하고 되돌리기, 못 되돌리면 제자리 확인 줄

색 토큰

라이트는 :root, 다크는 시스템 설정(prefers-color-scheme: dark, data-theme="light"면 제외)과 data-theme="dark" 두 곳에 같은 값. 다크는 뒤집은 값이 아니라 따로 잰 값이에요. 숫자는 회의에서 잰 바탕 대비.

토큰쓰는 곳라이트다크

글자 · 모양 · 간격

  • 글꼴 Pretendard Variable(한글·본문) + JetBrains Mono(숫자·라틴·명령). 지금 쓰는 CDN 그대로
  • 크기 날짜 mono 28/500(모바일 22) · 화면 제목 24/700 · 큰 소식 제목 21/800(800은 워드마크·큰 소식·첫 화면 제목만) · 카드 제목 17/700 · 본문 15/1.65 최대 40em · 라벨·칩·버튼·한글 메타 13 · mono 12(숫자·라틴만)
  • 모서리 6 칩·작은 버튼 / 8 입력·버튼·나에게·코드 / 10 카드 / 12 패널·시트 / 999 상태 알약·토글
  • 그림자 카드는 그림자 없이 1px 선. 그림자(--shadow-float)는 시트·토스트·메뉴·저장 바에만
  • 간격 옆 여백 16 / 24(768px 이상) / 32(1200px 이상), 상단바 52 / 56. 중단점은 768·1200 둘
  • 로고 6×18px 블레이즈 막대 + 단색 toolscout 800. 더블 블레이즈는 '업계 큰 소식' 라벨에만

앱 셸

한 셸, 네 가지 계정 상태. 관리자 전용 셸이나 색은 없고 탭만 더하거나 뺀다. 위 '계정'을 바꾸면 맨 위 상단바가 다시 그려져요. 오른쪽은 같은 문서를 390px로 연 모바일 모습(하단 탭)이에요.

카드와 보드

카드 해부도: 머리줄 → 제목 → 요약(전부) → 나에게 → 검증·위험 한 줄(도구만) → 발바닥 줄. 장단점·검증 세부·설치 명령·왜 이 카드·관리자 트레이스 줄은 '자세히' 안. 관심없음은 한 줄로 접고 같은 자리에서 되돌린다. 아래는 Cards.today + Cards.mount 결과(가상 데이터)예요.

화면에서 쓰는 법

<header id="appbar"></header> + <main class="wrap ...">
모든 화면의 뼈대. 스크립트는 /static/app.js(필요하면 /static/cards.js), 스타일은 /static/app.css 하나(cards.css·legacy.css를 불러온다)
await TS.shell({ active, ask = true })
로그인한 화면의 상단바·하단 탭·질문 시트(ask.js를 불러옴)·DEV·관리자 칩. 반환은 /api/me
TS.bare({ actions: [[주소, 글자, 주 버튼]], ctabar })
세션 없는 화면의 브랜드만 있는 상단바. ctabar면 모바일 아래 고정 바
TS.ic(이름, "ic-12"|"ic-18"|"ic-22") · TS.say(글) · TS.confirmLine(버튼, { html, ok, onOk }) · TS.setPending(n) · TS.count(n) · TS.stamp(iso) · TS.copy
아이콘, 토스트, 제자리 확인 줄, 승인 대기 수, 99+ 표시, 절대 시각 "10.06 14:20", 복사(data-copy 버튼은 자동)
Cards.mount(el, briefing, { day, level, abs, weights, one, empty })
큰 소식 띠 + 뉴스·도구 레인. 피드백 버튼과 사유·소감·관심없음 되돌리기까지 붙는다. Cards.readonly = true면 버튼 없이(예시)
Cards.today(briefing, { basis, status, demo }) · Cards.pipe(briefing) · Cards.card(card)
오늘 머리줄(mono 날짜·상태줄·기준 줄·파이프라인·어떻게 골랐나), 파이프라인 한 줄, 카드 한 장
button.more[aria-controls]
