# web/

프레임워크 없는 정적 HTML·JS 웹앱. 폰 폭은 카드 한 줄, PC(900px 이상)는 두 칸. 상태: 로그인 구현, 나머지 진행 중 (계획안 9.3·9.4).

## 파일
- `app.css`: 공통 스타일 (카드·버튼·질문창·설정·반응형)
- `app.js`: 공통 도우미 `TS` (API 호출·401이면 /login·HTML 이스케이프·상단 메뉴)
- `login.html`: 이메일 매직링크 요청, 만료·재사용·위조 안내, 카카오 버튼 자리(준비 중)
- `index.html`: 오늘 브리핑 (진행 중)
- `settings.html`, `history.html`, `f.html`: 설정·지난 브리핑·메일 피드백 링크 결과 (진행 중)

## 들어오고 나가는 데이터
- 들어옴: `/api/` JSON 응답 (세션 쿠키)
- 나감: 로그인·프로필·피드백·질문 요청 (JSON)

## 관련
- `routes/pages.py`: 화면 라우팅, 루트 `main.py`: `/static`으로 이 폴더를 연다
- 외부 텍스트(기사 제목·요약·모델 답)는 `TS.esc`로 이스케이프, 링크는 http(s)만
